# 2026-10-29 — الثيم المعتمد والأيقونات الموحّدة على كل المنصة

## الهدف
اعتماد مظهر مرح موحّد (تدرّجات، أزرار بحافة ضغط، أيقونات Fluent Emoji 3D) وتطبيقه على كل المنصة بما فيها الإعدادات — باستبدال نظيف للأصناف القائمة لا تركيب أنماط موازية.

## ما تغيّر
- **جديد `src/ui/`**: `ui.css` (المتغيرات والأنماط)، `Emoji.jsx` (المكوّن)، `fluentEmoji.js` + `localEmoji.js` (خرائط مولَّدة).
- **استبدال مظهر** الأصناف `btn-primary/secondary/accent`, `bottom-nav-*`, `role-pill-btn`, `side-nav-icon`, `toast-banner`, `settings-btn`, `atr-btn`, `tag-badge.info`, `ch-cat-btn`, `ch-slot-btn`, `ch-continue-btn` — بأسمائها القديمة.
- **`<Emoji>`** مُدرج في 42 ملف JSX (125 موضعًا) آليًا: نص JSX يبدأ بإيموجي داخل وسم.
- جزيرة التعلم: بطاقات الدروس `state-done/current/next`، الدرس الحالي ينبض، «تحدي الإتقان»/«دليل الأهل» أزرار.
- ولي الأمر: أزرار واتساب/التقارير/الترقية بالتدرّج؛ الروابط السريعة `quick-link`.
- النوافذ: إلغاء → `btn-ghost`، التالي/إتمام → `btn-secondary`.
- ثوابت الأزرار اليدوية في `MySpace`, `AssignStudents`, `RecordingsReview` حُدِّثت قيمها.
- **استضافة ذاتية**: `public/emoji/` (175 أيقونة)، `scripts/sync-emoji.py`، كاش PWA `fahem-emoji` خارج precache.

## الأدلة
- `npm run build` ناجح؛ precache بقي 53 ملفًا / 1.99MB.
- `node --test src/lib/*.test.js`: 58/58.
- متصفح محلي: 18/18 صورة من `/emoji/` و0 من CDN؛ الإنتاج يخدم `/emoji/1f393.png` بـ 200.
- لقطات headless للصفحة الرئيسية بعرض 390px: أيقونات 3D موحّدة، بلا كسر.

## لم يُتحقق منه
- صفحات الطفل/ولي الأمر/الإدارة خلف تسجيل الدخول **لم تُعاين بصريًا** (لا حساب تجريبي). التحقق بالكود والبناء فقط.

## دروس
- الاستبدال الآلي بالـ regex أصاب `<nav>`/`<div>` بالخطأ مرة؛ راجع الـ diff دائمًا قبل الالتزام.
- على Windows، `glob` يعيد مسارات بـ `\` — طبّع إلى `/` قبل حساب عمق الاستيراد النسبي.
- jsDelivr ردّ 403 عشوائيًا على بعض الملفات؛ GitHub raw بديل في السكربت.
