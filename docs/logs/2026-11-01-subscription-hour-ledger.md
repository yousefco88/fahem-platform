| العنصر | التصميم |
|---|---|
| الوحدة | دقائق صحيحة (الحضور بالدقائق؛ المنحة = ساعات الـsnapshot × 60) |
| الجدول | `subscription_hour_ledger` append-only: `grant` (+) / `debit` (−) / `reversal` (يعكس قيدًا واحدًا بعينه مرة واحدة) |
| Idempotency | `unique (source_type, source_id, source_version)`؛ نسخة الحضور = `updated_at` |
| تصحيح المعلم | إعادة الترحيل تُنشئ **عكسًا** للخصم السابق + خصمًا جديدًا؛ تصحيح إلى «غائب» = عكس فقط |
| الرصيد | `contract_balance_minutes(contract)` = مجموع القيود؛ **لا يُسمح بالسالب** |
| اختيار العقد | عقد واحد نشط يغطي الطفل + المادة (`all` أو ضمن `child_subscription_subjects`) ويحوي `session_date`؛ صفر أو أكثر من واحد = رفض صريح |
| التسلسل | `select … for update` على صف العقد قبل قراءة الرصيد؛ **حارس يرفض أي عزل غير READ COMMITTED** (لأن القراءة بعد القفل تحت RR ترى snapshot قديمًا) |
| الثبات | trigger يرفض UPDATE/DELETE حتى من مالك الجدول |
| الصلاحيات | RPCs للإدارة فقط (`grant_contract_minutes`, `post_live_attendance_debit`, `reverse_ledger_entry` بسبب إلزامي)؛ لا كتابة للعميل؛ ولي الأمر يقرأ قيود أطفاله فقط |
