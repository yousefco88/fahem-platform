## 🎯 المحاور الرئيسية للتحسين

### 1️⃣ تسهيل التنقل (Navigation UX)

#### المشكلات الحالية:
- [ ] القائمة السفلية (BottomNav) لا تظهر الصفحة النشطة بوضوح كافٍ
- [ ] "المزيد" يفتح قائمة منسدلة — قد تربك المستخدم الجديد
- [ ] لا يوجد breadcrumbs في الصفحات الداخلية
- [ ] زر "العودة" غير موجود في بعض الشاشات

#### الحلول المقترحة:
- [ ] **P1** إضافة مؤشر بصري أقوى للصفحة النشطة (لون + خط تحتي)
- [ ] **P2** إضافة breadcrumbs: `الرئيسية > مساحة الطفل > اللغة العربية`
- [ ] **P2** زر عودة ← في أعلى يمين كل صفحة فرعية
- [ ] **P3** إخفاء القائمة السفلية أثناء الدروس/الامتحانات (تركيز كامل)

---

### 2️⃣ تجربة الطفل (Child UX)

#### النقاط الإيجابية ✅:
- التحية الشخصية "جاهز نفهم ونلعب سوا يا أحمد؟"
- الألوان الجذابة والتدرجات
- الثعلب التفاعلي 🦊
- "تابِع من حيث توقفت" — ممتاز

#### التحسينات المقترحة:
- [ ] **P1** صوت ترحيب عند فتح الصفحة (اختياري في الإعدادات)
- [ ] **P1** إضافة أصوات تفاعلية عند النقر على الأزرار
- [ ] **P2** نظام مكافآت بصرية (confetti عند إتمام درس)
- [ ] **P2** شريط تقدم يومي واضح "أنجزت 2 من 3 مهام اليوم 🎯"
- [ ] **P3** avatar/صورة رمزية قابلة للتخصيص للطفل
- [ ] **P3** "جزيرة" تفاعلية (gamification) تتطور مع التقدم

---

### 3️⃣ تجربة ولي الأمر (Parent UX)

#### المشكلات الحالية:
- [ ] الصفحة مكتظة بالمعلومات
- [ ] لا يوجد ملخص سريع "في نظرة واحدة"
- [ ] أجندة امتحانات السفارة طويلة جداً

#### الحلول المقترحة:
- [ ] **P1** بطاقة ملخص في الأعلى:
  ```
  📊 أحمد هذا الأسبوع: 3 دروس | 0 اختبارات | 0% إتقان جديد
  ```
- [ ] **P1** طي/فتح الأقسام (collapsible sections)
- [ ] **P2** إشعارات push عند إنجاز الطفل درس
- [ ] **P2** مقارنة أسبوعية "هذا الأسبوع vs الأسبوع الماضي"
- [ ] **P3** تقرير PDF قابل للتحميل
