# مستودع مصادر المناهج — فاهم

فهرس موحّد لمصادر المحتوى التعليمي قبل تحويله لدروس المنصة. الملف الرئيسي: `sources.json`.

## الأقسام

### 1) `ministry_books` — كتب الوزارة الرسمية ✅ قابلة للاستخدام في المنصة
- المصدر: المكتبة الإلكترونية الرسمية `ellibrary.moe.gov.eg` (الملفات على `elearnningcontent.blob.core.windows.net` — متاح دولياً).
- ⚠️ موقع المكتبة نفسه **محجوب جغرافياً خارج مصر (403)** — ميزة تنافسية لفاهم: الأسر المغتربة لا تصل إليه مباشرة.
- المنزَّل: 6 كتب الصف الأول الابتدائي ترم أول (عربي، اكتشف، رياضيات، انجليزي Connect، دين إسلامي، دين مسيحي) — نسخة العام 2025/2026 (مجلد 2027 غير منشور بعد — يُعاد الفحص مطلع العام الدراسي).
- الحقوق: `official-ministry` → مسموح التحويل والرفع داخل المنصة.

### 2) `items` — كتب خارجية تجارية ⛔ لا تُرفع ولا تُعرض للأسر
- المصدر: قناة `t.me/talebmoeser` → موقع talepmoaser.com (نسخ PDF غير مرخصة لكتب المعاصر/سلاح التلميذ/الأضواء...).
- الاستخدام المسموح: **تحضير داخلي للمعلم فقط** (`teacher-prep-only-no-upload`). تنزيلها يدوي عبر تليجرام ديسكتوب إن لزم.

## القواعد
1. أي مصدر جديد يُضاف لـ `sources.json` بحقول: title, grade, subject, term, publisher, rights, usage, status.
2. دورة الحالة: `idea → review → accepted → converted` (converted = صار درساً بالمنصة بمرجع).
3. مجلد `files/` **خارج Git** (أحجام كبيرة) — النسخ الاحتياطي مسؤولية منفصلة.
4. لا يُرفع لـ Supabase Storage إلا ما حقوقه `official-ministry` أو ما نملك حقه.
