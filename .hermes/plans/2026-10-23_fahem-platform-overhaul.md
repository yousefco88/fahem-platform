# خطة التحسين الكلي لمنصة "فاهم" التعليمية

> **For Hermes:** نفّذ هذه الخطة مرحلة-بمرحلة بعد موافقة يوسف على كل مرحلة. لا تنفيذ بدون "ابدا".

**الهدف:** تحويل "فاهم" من نموذج أولي (Prototype) إلى منصة إنتاجية جاهزة لاستقبال طلاب حقيقيين ومدفوعات حقيقية.

**البنية الحالية:** React 18 + Vite 6 + Express + Supabase + Vercel — 13 مكوّن (6,371 سطر) — بدون Router، بدون Auth حقيقي، Bundle واحد 487KB، اختبار واحد فقط للسيرفر.

**الحالة:** idea → proposed (بانتظار الموافقة)

**لماذا أولاً:** لا يمكن إطلاق منصة تحتوي لوحة إدارة مفتوحة.

| المهمة | الملفات | معيار القبول |
|--------|---------|--------------|
| 1.1 تفعيل Supabase Auth (بريد + كلمة مرور + Google) | `src/lib/supabase.js`, مكوّن `AuthGate.jsx` جديد | تسجيل/دخول/خروج يعمل فعلياً |
| 1.2 جدول `profiles` مع أدوار (parent/teacher/admin) | `supabase/schema.sql` + migration جديد | كل مستخدم له دور محفوظ |
| 1.3 حماية المسارات — Admin/Teacher خلف تحقق الدور | `App.jsx`, `AdminDashboard.jsx`, `TeacherStudio.jsx` | زائر بدون دور admin يُرفض |
| 1.4 RLS Policies على كل جداول Supabase | `supabase/schema.sql` | قراءة/كتابة حسب الدور فقط — اختبار بـ anon key |
| 1.5 نقل أسرار السيرفر لمتغيرات بيئة Vercel | `server/server.js`, Vercel dashboard | صفر أسرار في الكود |

**تقدير:** 2-3 جلسات عمل.
