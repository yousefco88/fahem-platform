# فاهم — نموذج أولي لمنصة تعليمية

منصة عربية قيد التطوير تستهدف أبناء المصريين بالخارج. التصور الحالي يبدأ بالصف الأول الابتدائي، مع مواد تجريبية في العربية والرياضيات. الهدف بناء تجربة آمنة يكون التسجيل فيها لولي الأمر، مع مدرسين حقيقيين بعد التحقق منهم ومراجعة المحتوى أكاديميًا.

> هذا المستودع نموذج واجهة محلي، وليس منصة تشغيلية أو معتمدة. المحتوى والطلاب والطاقم والجداول والسجل الإداري المعروض لأغراض العرض فقط. لا توجد حسابات حقيقية أو قاعدة بيانات مشتركة أو دفع أو بث مباشر أو إرسال رسائل. لا تستخدمه لحفظ بيانات أطفال حقيقية.

## المتاح في النموذج

- واجهات صفحة تعريفية، ولي الأمر، الطفل، المعلم، والإدارة.
- تفاعل تعليمي ومتابعة تقدم محلية على المتصفح.
- إدارة مسودات محتوى محلية وإرفاق PDF وفيديو تجريبيين في IndexedDB.
- معاينة فصل وأدوات تعليمية تجريبية؛ ليست اتصالًا بين مستخدمين.

تظل الملفات والبيانات على المتصفح والجهاز المستخدم، وقد تضيع عند مسح بيانات المتصفح. ليست هناك نسخة احتياطية أو مزامنة بين الأجهزة. ملفات PDF والفيديو في المتصفح لا تصل إلى المعلمين أو الأسر الأخرى.

## التشغيل محليًا

المتطلبات: Node.js وnpm.

```bash
npm install
npm run dev
npm run build
```

لتجربة شريحة الحسابات التجريبية افتح نافذة طرفية ثانية وشغّل:

```bash
npm run api:dev
```

ثم افتح «حساب ولي الأمر (تجريبي)» من شريط الواجهة. يعمل الخادم على `127.0.0.1:3011` وقاعدة SQLite محلية داخل `data/fahem.sqlite`؛ لا تعرض هذا API على الشبكة ولا تستخدم بيانات حقيقية. للتوقف احذف قاعدة الاختبار المحلية يدويًا بعد إيقاف الخادم إذا لم تعد تحتاج الحسابات التجريبية.

## التقنيات

- React 19 وJavaScript
- Vite
- CSS مخصص
- Node.js HTTP API وSQLite محليان لنموذج حساب ولي الأمر والأبناء؛ كلمة المرور مخزنة كاشتقاق scrypt، والجلسة في Cookie محمية HttpOnly/SameSite
- IndexedDB للمرفقات المحلية، وlocalStorage لبعض إعدادات النموذج وسجلاته

## ما قبل التشغيل الحقيقي

يلزم إنشاء خلفية وقاعدة بيانات ومصادقة وصلاحيات خادمية، تخزين ملفات آمن، نسخ احتياطي واستعادة، نظام حصص واتصال موثوق، موافقات ولي الأمر وحماية بيانات الأطفال، مراجعة أكاديمية موثقة للمناهج، واختبارات قبول ونشر مراقب. لا تمثل الواجهات الحالية إنجاز هذه المتطلبات.

اختبارات API: `npm run api:test`.
