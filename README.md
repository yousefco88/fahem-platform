# فاهم — منصة تعليمية قيد التأهيل

هذا المستودع هو مصدر كود منصة فاهم. **بحسب تأكيد يوسف بتاريخ 2026-10-27، النسخة منشورة في المستودع وعلى خادم، ومتصلة بقاعدة بيانات حية لأغراض التأهيل قبل النقل إلى خادم خاص.** هذا الوصف لا يعني أن كل وظيفة اكتملت أو اختُبرت لكل الأدوار؛ حالة كل مسار تُوثق بحسب أدلتها.

تضم الشيفرة الحالية مصادقة Supabase، أدواراً ومسارات محمية، وميزات تقرأ/تكتب إلى Supabase وفق السياسات القائمة. توجد أيضاً بيانات ثابتة/احتياطية وبعض أدوات العرض والتجارب المحلية؛ لا تفترض أن كل عنصر ظاهر يمثل بيانات حية. تحقّق من مصدر البيانات وحالة الاستعلام لكل ميزة قبل استخدامها تشغيلياً، ولا تستخدم حسابات الإنتاج لاختبارات الكتابة.

## المتاح في الشيفرة الحالية

- **الواجهات**: صفحة هبوط (أقسامها قابلة للتحرير من الإدارة)، ولي الأمر (`/parent`, `/account` «مساحتي»)، جزيرة الطفل (`/child/*`)، المعلم (استوديو، «مناهجي»، الحصص)، الإدارة (`/admin`: مستخدمون وأدوار، دعوات، عائلات، صفوف، منهج ومراجعة، تسجيلات، إعدادات الموقع، إعدادات المساعد، تحليلات).
- **المنهج**: CMS في Supabase بسير مسودة → مراجعة → نشر، بنك أسئلة لكل درس مع سجل محاولات، مراجع ودليل أهل، سجل مصادر (كتب وزارية).
- **الحصص المباشرة**: جدول لكل طفل، معلم معيَّن، رابط اجتماع عبر RPC، نافذة انضمام 15 دقيقة، سجل حضور، تسجيلات مرتبطة بالدرس في Storage بمراجعة الإدارة.
- **المساعد الذكي `/ai-tutor`**: Edge Function `ai-tutor-chat` (مزوّد NVIDIA)، مشروط بموافقة ولي الأمر، قاعدة معرفة من مصادر المنهج مع OCR داخل المتصفح، مراجعة المعلم للمحادثات.
- **التلعيب**: Streak/XP، شارات، مؤثرات.
- **الحساب**: أدوار (`admin`, `teacher`, `content_editor`, ولي أمر)، تقرير PDF أسبوعي، رؤى لكل طفل، تقييم مُصحَّح على الخادم.
- **PWA** مع شريط تحديث، وضع ليلي/نهاري عام، تعدد لغات، ثيم موحّد بأيقونات Fluent محلية.
- **محذوف عمدًا**: محاكي امتحان السفارة (أُزيل كليًا 2026-10-27)، كل البيانات التجريبية/المفبركة، الفصل المحاكى، قائمة «المزيد» في الجوال.
- متابعة التقدم مرتبطة بمصدر البيانات المستخدم في كل شاشة؛ بعض التفاعلات أو التخزين التجريبي محلي في المتصفح. وجود التدفق في الشيفرة لا يثبت وحده اكتمال اختباره في الإنتاج لكل دور.

التاريخ الكامل (191 التزامًا من 2026-10-23) موثّق يومًا بيوم في **[`docs/CHANGELOG.md`](docs/CHANGELOG.md)**، وتفاصيل كل جلسة في `docs/logs/`.

المرفقات المخزنة في IndexedDB أو الملفات المحفوظة محلياً لا تصل تلقائياً إلى مستخدمين آخرين. لا تمسح بيانات المتصفح قبل التأكد من مصدر الحفظ والنسخ الاحتياطي الخاص بالميزة.

## التشغيل محليًا

المتطلبات: Node.js وnpm.

```bash
npm install
npm run dev
npm run build
```

## API محلي معزول للتطوير

يوفر `server/server.js` خدمة Node.js مستقلة بقاعدة SQLite محلية (`data/fahem.sqlite`) ومسارات API للتطوير والاختبار، على `127.0.0.1:3011`. هذه الخدمة **ليست** قاعدة بيانات أو API الخادم المنشور الذي تتصل به شيفرة Supabase، ولا ينبغي نشرها أو إدخال بيانات حقيقية فيها.

لتشغيلها محليًا في نافذة ثانية:

```bash
npm run api:dev
```

اختباراتها: `npm run api:test`. لا تحذف قاعدة الاختبار إلا بعد التحقق من أنها محلية وغير مطلوبة.

## طبقة الواجهة الموحّدة (`src/ui/`)

المظهر المعتمد (2026-10-29): تدرّجات لونية، أزرار دائرية بحافة ضغط، أيقونات **Fluent Emoji 3D** (Microsoft، رخصة MIT) موحّدة على كل الأجهزة.

- `src/ui/ui.css` — المتغيرات (`--g-primary`, `--g-fun`, `--g-mint`, `--press`…) وأنماط `btn-primary/secondary/accent/ghost/pink/sky`، الشريط السفلي، التنبيهات، بطاقات الحالة `state-done/current/next`، أنماط الإعدادات والإدارة، والوضع الليلي. يُستورد في `main.jsx` بعد `index.css`.
- `src/ui/Emoji.jsx` — مكوّن `<Emoji>🏠 نص</Emoji>` يستبدل الإيموجي بصورة. **الترتيب:** `public/emoji/<codepoint>.png` محليًا ← CDN jsDelivr عند الفشل ← النص العادي. الإيموجي غير المعروف يبقى نصًا.
- `src/ui/fluentEmoji.js` (خريطة المستودع، مولَّدة) و`src/ui/localEmoji.js` (الأيقونات المنسوخة محليًا، مولَّدة).
- `public/emoji/` — ~175 أيقونة (~5.7MB). **خارج** precache الـ PWA عمدًا؛ تُخزَّن عند الطلب عبر `runtimeCaching` باسم `fahem-emoji` (CacheFirst، 180 يومًا) في `vite.config.js`.
- **عند إضافة إيموجي جديد في الكود:** شغّل `python scripts/sync-emoji.py` — يحصر المستخدم فعلًا في `src/`، ينزّل الناقص، ويعيد توليد `localEmoji.js`.
- قاعدة: استبدال نظيف للأصناف القائمة بأسمائها، لا تركيب أنماط موازية. كتل `style={{}}` الخاصة بالتخطيط تُترك كما هي ولا تُغيَّر إلا عند لمس الملف لسبب آخر.

## التقنيات

- React 19 وJavaScript وVite وReact Router
- Supabase للمصادقة والبيانات بحسب تدفق كل ميزة والسياسات المطبقة
- CSS مخصص
- Node.js HTTP API وSQLite محليان لخدمات التطوير والاختبار المعزولة؛ كلمة المرور مخزنة كاشتقاق scrypt، والجلسة في Cookie محمية HttpOnly/SameSite
- IndexedDB للمرفقات المحلية، وlocalStorage لبعض إعدادات النموذج وسجلاته

## التأهيل قبل النقل إلى خادم خاص

النشر الحالي والاتصال بقاعدة Supabase الحية مؤكّدان من يوسف؛ لم يُنفذ في هذه الجلسة نقل للخادم أو تعديل لقاعدة الإنتاج. قبل النقل، يلزم جرد متغيرات البيئة دون تدوين قيم الأسرار، حصر migrations المطبقة فعلياً، وضع خطة نسخ احتياطي واستعادة واختبارها، حسم استضافة الملفات ومصادقة المستخدمين وسياسات RLS، والتحقق من صلاحيات كل دور في بيئة اختبار وحسابات مأذون بها، ثم إعداد خطة cutover وrollback ومراقبة. لا تعِد إنشاء خلفية/قاعدة من الصفر ولا تنفذ النقل قبل اكتمال الجرد والموافقة.
