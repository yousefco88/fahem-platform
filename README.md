# 🌟 منصة «فاهم» — التعليم الحي والمتقن لأبنائنا بالخارج
### *Fahem Educational Platform for Egyptian Expatriates*

> منصة تعليمية وتفاعلية متكاملة مصممة خصيصاً لأبناء المغتربين المصريين حول العالم، ترتكز على **التعليم الحي التفاعلي في مجموعات مصغرة (4 طلاب)**، وتغطية **12 مادة ومساراً تعليمياً معتمداً** وفق منظومة التعليم المصري الحديث ومقررات امتحانات السفارات («أبنائنا في الخارج»).

---

## 🏛️ الميزات والركائز الأساسية للمنصة

### 1. 🚀 مساحة الطفل التفاعلية (`ChildUniverse`)
* **خريطة مغامرة ذكية لـ 12 مادة:** (اللغة العربية، الرياضيات، Connect، Connect Plus للغات، Math بالإنجليزية، اكتشف، تاريخ ومعالم مصر، ICT، المهارات الحياتية، ونور البيان والخط).
* **الثعلب الناطق «فاهم»:** تفاعل صوتي فوري يشجع الطفل ويوجهه باستخدام الذكاء الاصطناعي وتقنيات Web Audio و Web Speech.
* **ألغاز تركيب الكلمات والمقاطع الصوتية:** تعزيز الإدراك الحركي والبصري للحروف والمدود.
* **فلسفة التعلم للإتقان (Mastery Learning):** إعادة الأنشطة والاختبارات دون رسوب حتى الوصول لنسبة 100% وتحقيق شارات التميز.

### 2. 🎥 استوديو الفصل الحي المتقدم والميكرو-جروب (`LiveClassroomSuite`)
* **فصول مصغرة (4 طلاب فقط + المعلمة):** تضمن تركيزاً فائقاً ومشاركة صوتية لكل طفل.
* **زر رفع اليد الذكي (✋ Raise Hand):** مع تنبيه صوتي وشارة ذهبية متوهجة فوق كاميرا الطالب.
* **شريط التفاعل الحركي العائم:** إرسال تصفيق 👏، نجوم ⭐، قلوب ❤️، واحتفال بالكونفيتي 🎉 تطفو على شاشة الفصل.
* **السبورة التشاركية الحية:** رسم وكتابة مشتركة بين المعلمة والطلاب مع تحكم المعلمة في أذونات الكتابة.
* **تحدي السفارة السريع (Live Pop-Quiz):** إطلاق أسئلة امتحانية سريعة على شاشات الطلاب ورصد الإتقان اللحظي.

### 3. 🇪🇬 محاكي اختبارات السفارة الرسمي (`EmbassyExamSimulator`)
* **محاكاة مطابقة لمنصة امتحانات «أبنائنا في الخارج» بوزارة التربية والتعليم المصرية.**
* **مؤقت تنازلي رسمي (25 دقيقة)** لتدريب الطالب على إدارة الوقت.
* **كشف درجات رسمي معتمد (PDF Report Card):** بتقييم الألوان الوزاري الحديث (**اللون الأزرق — فاق التوقعات 🟦**) مع ختم الأكاديمية قابل للطباعة والحفظ في ملف الأنشطة.

### 4. 👨‍👩‍👦 لوحة ولي الأمر وحاسبة فروق التوقيت (`ParentDashboard`)
* **إدارة وتتبع عدة أبناء (Multi-Child Switcher):** التبديل بين ملفات الأبناء بضغطة زر.
* **حاسبة التوقيت الدولي الآلية:** تحويل مواعيد الحصص من توقيت القاهرة إلى التوقيت المحلي بدول الخليج (السعودية، الإمارات، الكويت) وأوروبا وأمريكا.
* **أجندة امتحانات السفارة الرسمية:** مواعيد استمارة التقدم، تقييمات الفصل الأول، والامتحانات النهائية.
* **أدلة المذاكرة المنزلية (5 دقائق):** نصائح تربوية سريعة للوالدين لدعم تعلم أطفالهم في الغربة.

### 5. ⚙️ لوحة التحكم والإدارة المركزية والتدقيق (`AdminDashboard - Super Admin`)
* **محرر المناهج والصفحات (Curriculum CMS):** إضافة وتعديل ونشر الدروس والأسئلة وأوراق العمل فوراً.
* **إدارة الصلاحيات والأدوار (RBAC):** تحديد صلاحيات المشرفين والمعلمين ومسؤولي الدعم.
* **سجل التدقيق التاريخي (Audit Trail):** توثيق زمني غير قابل للحذف لكل العمليات مع وضع الرقابة الخفية (Ghost Mode) لمتابعة جودة الفصول الحية.
* **إحصاءات الاشتراكات الدولية:** توزيع الطلاب في السعودية والخليج وأوروبا ومعدلات التجديد.

## 💻 التشغيل والتطوير المحلي (Local Development)

### المتطلبات الأساسية
* **Node.js** (الإصدار 18 أو أحدث)
* **npm** أو **yarn**

### خطوات التثبيت والتشغيل
```bash
# 1. استنساخ المستودع
git clone https://github.com/yousefco88/fahem-platform.git
cd fahem-platform

# 2. تثبيت الحزم والمكتبات
npm install

# 3. تشغيل خادم التطوير المحلي
npm run dev

# 4. بناء نسخة الإنتاج
npm run build
```

## 🛠️ التقنيات المستخدمة (Tech Stack)
* **Frontend:** React 19, JavaScript (ESNext)
* **Build Tool:** Vite
* **Styling:** Modern Vanilla CSS (Custom Design System adhering to Brand Identity)
* **Audio & Synthesis:** Web Audio API (Chime oscillators) & Web Speech API (Arabic Native Reader)
* **Canvas:** HTML5 Canvas (Collaborative Whiteboard & Confetti particle engine)
